# 微孔板梯度稀释规划器（本地 Web 应用）

供湿实验研究人员在本机规划 24 / 96 孔板梯度稀释的 Flask 应用。**所有计算均在本机完成**，
不向任何外部服务发送数据；实验与执行记录保存在本地 SQLite 文件 `dilution.db`。

## 功能

- **参数录入**：24/96 孔板、母液浓度与备量、目标浓度梯度、每孔体积、平行样、空白孔、
  多档移液器量程、最小混匀体积、死体积、允许连续稀释级数、单孔容量。
- **物料守恒求解**：自动选择 母液直接稀释 / 逐级系列稀释（同平行样优先成链），
  输出每孔来源、分析物加入量、稀释液补加量、实际终浓度与执行顺序；
  来源孔自动按「终体积 + 供出量 + 死体积」给出配制体积。
- **交互式板图**：拖拽调整孔位、双击锁定/解锁、单击查看孔详情、可手动指定每孔来源；
  锁定孔在重算时位置/来源保持不变，其余孔自动重排。
- **即时可行性检查**：移液量越界（自动分次或给出量程边界最接近方案）、孔容量不足、
  浓度不可达、来源循环、无效来源、孔位冲突/不足、低于最小混匀体积、死体积不足、
  超连续稀释级数、母液备量不足；每个不可行孔给出**最接近可行方案与具体偏差**。
- **台面步骤**：按「空白孔 → 浓度逐级」分组、每孔先稀释液后分析物，逐步勾选；
  勾选、取消、重置与每次重算都写入执行日志，重算后已勾选步骤尽量保留。
- **导出**：带板图的打印工作单（可直接打印/另存 PDF，含签字栏）与 CSV 明细表
  （孔位明细、步骤、问题偏差、物料汇总）。
- **内置 3 个示例**：标准 10 倍系列稀释、24 孔板半数稀释、含各类冲突的演示实验。

## 运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

浏览器打开 <http://127.0.0.1:5000>。

（系统 Python 已装 Flask 时也可直接 `python3 app.py`。）

| 文件 | 说明 |

## 计算说明

对目标浓度 C_t、终体积 V_f、来源液浓度 C_s，由物料守恒：

```
分析物转移量 Va = C_t · V_f / C_s
稀释液补加量 Vd = V_f − Va
```

- 多级稀释时，C_s 为**来源孔内液体的实际浓度**（逐级计算，同平行样优先）；
- 来源孔配制体积 = 终体积 + 向所有下游孔的供出总量 + 死体积（补足部分用稀释液，不改变浓度）；
- Va 或 Vd 落在移液器量程外时，优先在量程内分次移液；无法分次时给出量程边界的
  最接近体积，并计算由此产生的终浓度偏差；
- 母液浓度低于目标浓度时标记“浓度不可达”，按“满孔取液”给出可达上限浓度。
